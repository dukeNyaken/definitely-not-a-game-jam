# prototype — сгенерированные герои и босс в игре

Конвейер `experiments/char3d`: текст → картинки (Qwen-Image 2.1) → 3D (Hunyuan3D 2.1) → лоу-поли → скелет → вещи. Анимации взяты из библиотеки Quaternius UAL (CC0) и проигрываются через ретаргет. Ветка `char3d-generated-heroes`.

| Что | Где |
|---|---|
| варианты героя (меню «Герой»: Варвар / Тамплиер / Космодесант / Рыцарь) | `heroes/<id>.glb`, список — `heroes.json` |
| босс в вещах варианта, посаженных по его росту | `boss/<id>.glb` |
| замер шага на каждом теле | `measure/<тело>.json` |
| библиотека анимаций (46 клипов) | `anims/ual.glb` |
| карты костей для ретаргета | `retarget/bonemap_*.tres` |
| что и как играет (пишется руками) | `animation.json` |

Всё, кроме `animation.json` и этого файла, пишет `experiments/char3d/export_prototype.py`. Состав вариантов задаёт `experiments/char3d/data/prototype.json`, правила посадки вещей — `data/equipment.json`.

## Как устроено в игре

`SkinnedActorModel` (`scripts/visual/skinned_actor_model.gd`) — наследник `ActorModel`. Вспышка, контурный свет, тень, добавки свойств и потоки жертвы работают из базового класса.

- **Выбор модели.** `game.gd` и витрина меню берут героя через `SkinnedActorModel.for_hero()`, `boss_director.gd` берёт босса через `for_boss()`. Если прототипа нет, остаются процедурные модели. Выбор героя хранится в `user://hero.cfg`.
- **Вещи.** Вещь — сетки `item_<слот>[__<часть>][_L|_R]` на скелете. Часть тела под ней — `hide_<слот>[__<часть>]`. Всё до «__» — один слот игры: доспех — это `item_armor` (кираса) и `item_armor__legs` (поножи). Пока вещь надета, часть тела спрятана, поэтому тело не проступает сквозь вещь ни в одной позе. Пожертвованная вещь исчезает, у босса вещи меняются по фазам.
- **Кираса и поножи** — не сетки Hunyuan, а оболочки из самого тела, раздутые на 1.4–2.2 см и развёрнутые прямо на картинки вещи спереди и сзади (`fit: shell` в `equipment.json`). Сидят без зазоров, гнутся с телом, спина закрыта целиком.
- **Витрина меню.** Вещи на кольце — вещи выбранного героя: `GeneratedItemDisplay` берёт сетки `item_*` из его модели без скелета и подгоняет под витрину. Перчатки и сапоги ставятся парой, меч вертикально. Кнопка «Герой» пересобирает и героя, и кольцо. Без прототипа на кольце остаются процедурные вещи.
- **PS1-вид делает игра.** Конвейер выдаёт только модель: сетку, скелет и текстуру 64–256 без сглаживания. Дрожь вершин, аффинные текстуры, низкое разрешение и палитру даёт ретро-шейдер и пост-обработка игры (`use_uv` в `retro_common.gdshaderinc`, режимы PS1/PS2 в `Render`). Своего PS1-шейдера у стенда `experiments/char3d/godot_test` больше нет.
- **Анимации** (AnimationTree):
  - **Ходьба и бег.** Берётся один клип, ближайший по скорости, с темпом «скорость / родная скорость клипа». Смесь клипов разного ритма укорачивала шаг, и было «катание на лыжах». Стопа на полу на 6 м/с теперь скользит 0.3–0.5 м/с вместо прежних 1.4.
  - **Бег вбок и наискосок.** `LocomotionModifier` поворачивает таз к направлению бега (до 85°), позвоночник поворачивается обратно, и торс остаётся к цели. Спиной вперёд клип идёт назад.
  - **Удары и заклинания.** Только верх тела, ноги продолжают шаг. У каждого удара своё окно клипа вокруг пика скорости кисти.
  - **Остальное.** Блок щитом, кувырок на рывке, реакция на попадание, смерть. У босса есть замах: рука поднимается по мере накопления удара.

## Проверка

```bash
godot --path . -s tools/anim_check.gd -- out=<папка> variant=<id>        # кадры состояний героя + замер скольжения стоп
godot --path . -s tools/anim_check.gd -- out=<папка> variant=<id> boss=1 # босс: стойка, замах, удар, смерть
godot --headless --path . -s addons/gut/gut_cmdln.gd                     # 32/32 (5 тестов на прототип)
godot --headless --path . -s tools/autoplay.gd -- seed=1234 speed=8 immortal=1
```

## Пересобрать или отключить

- Пересобрать: `cd experiments/char3d && python export_prototype.py [вариант ...]`.
- Отключить: удалить `prototype/heroes.json`. Игра вернётся к процедурным моделям.
- В `export_presets.cfg` (Windows) добавлено `include_filter="prototype/*.json"`, иначе конфиги не попадут в сборку.

**Лицензии.** Картинки, с которых сделаны модели и текстуры, нарисованы Qwen-Image 2.1. Его лицензия — **только некоммерческое использование**. У Hunyuan3D 2.1 свои территориальные ограничения. Перед коммерческим релизом нужно перегенерировать на свободной модели (Wan 2.2, Apache 2.0) или получить лицензию.
