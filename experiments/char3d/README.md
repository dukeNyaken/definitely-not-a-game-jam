# char3d — PS1-персонаж с экипировкой из текста: эксперимент

В игру не встроено: папка `experiments/` закрыта `.gdignore`. Состояние на 2026-10-02.

## Путь пользователя: 4 вкладки ComfyUI → Godot

| Вкладка | Что делает | Время |
|---|---|---|
| char3d 1 - персонаж | текст → Qwen (спереди + сзади) → Hunyuan → `output/char3d/<имя>/` | ~4 мин |
| char3d 2 - анимации | лоу-поли (1500 треуг., 256²) → скелет Mixamo → свои Idle/Walk/Attack | ~10 с |
| char3d 3 - вещь | текст → вещь → лоу-поли (300 треуг., 64²) → `output/char3d/item_<имя>/` | ~4 мин |
| char3d 4 - одеть и в Godot | персонаж + вещи по 7 слотам → `dressed.glb` → проект Godot с ретаргетом | ~10 с |

В Godot (`godot_test/`, F5):
- Tab переключает анимации, 1–7 снимают и надевают вещи, F включает и выключает PS1-эффекты.
- Персонаж играет 46 анимаций библиотеки Quaternius UAL (CC0): ходьба, бег, меч, удары, смерть и т.д.
- Проверка без рук: `godot --path godot_test -- --check` пишет кадры в `shots/`.

## Как устроено

```
text2img / img_edit / prep / img2mesh       картинки и сырая сетка (ComfyUI)
bake.py      лоу-поли + запекание текстуры с картинок спереди/сзади (Blender)
keypoints.py + rig.py + anim.py             скелет по DWPose, веса, свои анимации
dress.py     посадка вещей по data/equipment.json: каждая вещь — сетка item_<слот>
             на скелете тела (жёсткая — на одной кости, гнущаяся — веса с тела;
             расширение до выхода из тела, затем выталкивание на зазор)
to_godot.py  копия в проект + godot_import.py (ретаргет: BoneMap из data/bonemaps.json,
             fix_silhouette: А-поза ↔ Т-поза библиотеки)
comfy_nodes/ узлы char3d:* (обёртки над скриптами) + сторож 85 °C; в ComfyUI — junction
comfy_tabs.py графы вкладок из тех же функций; копии вкладок — comfy_workflows/
views.py     4 вида модели (поза покоя, pose=..., anim=Действие:кадр)
```

Числа лежат в `data/*.json`, у каждого есть пояснение `_why`. Каждый шаг печатает свои цифры:
- треугольники и текстура;
- IoU силуэта (совпадение формы) и вида сзади;
- вершины без веса;
- насколько вещь накрывает тело и насколько её пришлось расширить;
- температура видеокарты;
- результат ретаргета.

## Встраивание в игру (2026-10-03, без коммита)

```
gen_batch.py <субъект>[:рост] ...   пакетная генерация вещей и тел (вкладки 1-3 через API, продолжает с места)
data/prototype.json                 варианты героя: тело + вещь на слот; общее тело босса
export_prototype.py [вариант ...]   одеть героя и босса, выложить в prototype/ игры с ретаргетом, замерить шаг
```

Варианты: Варвар, Тамплиер, Космодесант (тело proto_hero), Рыцарь (knight_body). Босс — boss_body, в вещах варианта.

Правила посадки (`data/equipment.json`):
- Размеры задаются долями роста, поэтому вещи сами вырастают на боссе.
- Комплекты (`variants`) переопределяют правила: у варвара огромный меч в 0.75 роста, у рыцаря лёгкий в 0.46.
- Плоские вещи (`flatten`) сжимаются по глубине: Hunyuan «надувает» плоский щит в бревно.
- Расширение послойное и раздельное по ширине и длине. Расширяется только там, где вещь внутри тела.
- Части тела под вещью (`hide`, `hide_bones`) вырезаются в `hide_<слот>` и прячутся в игре, пока вещь надета.

Вырезка фона (`prep.py`): фон растёт от краёв кадра по плавным местам. Мягкая серая тень на полу и затенённый фон у тела входят в фон. Замкнутые просветы цвета фона (между руками и телом, между ногами) — тоже фон.

## Известное

- Текстуры полых вещей (шлем, кираса) пятнистые: бока и внутренность не видны ни спереди, ни сзади. Помогут виды сбоку той же правкой Qwen.
- Светлые подошвы ботинок у тела.
- Для вида сзади зерно у Qwen решает. Брак ловится по IoU: меньше 0.85 — сменить seed.
- Камера в предпросмотре 3D подтягивается, только когда вкладка открыта из файла.
- TRELLIS v1 не ставился: нужны CUDA Toolkit и MSVC.
